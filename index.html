Param AI Studio v1

Built as a static web app for iPad Safari and GitHub Pages. Chat inference uses Transformers.js with a compact text-generation model and WASM on-device processing. The model download is separate from this ZIP.

Video generation is an integration point, not an included cloud GPU. To generate videos, connect an authorized compatible service.

For GitHub Pages: Settings → Pages → Deploy from branch → main / root.

For privacy, chat history stays in this browser. A video prompt is sent to the endpoint you configure.
